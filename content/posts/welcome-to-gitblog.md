# Welcome to GitBlog!

This is an example blog post. The system uses a **static-first** approach: all posts are stored as Markdown files inside a GitHub repository.

## Features:
- 🚀 **Serverless:** No traditional database needed.
- ⚡ **Fast:** Statically generated with Next.js.
- 🎨 **Modern UI:** Designed with Tailwind CSS.
- 📝 **Admin CMS:** Built-in dashboard to edit posts directly.

When you edit this file from the `/admin` dashboard, it uses your GitHub Personal Access Token to commit the changes directly to your repository!
